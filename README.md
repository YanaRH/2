# Сервис управления рассылками (Django Mailing Service)

Курсовая работа по разработке веб-приложения на Django для автоматизации email-рассылок, управления клиентами и сбора статистики.

## Стек технологий

- **Язык:** Python 3.x
- **Фреймворк:** Django 4.x
- **Асинхронные задачи:** Celery (для фоновой обработки)
- **Кэширование:** Django Cache Framework
- **Стиль кода:** Проверка через flake8

## Функционал

Проект реализует полный цикл работы с рассылками согласно техническому заданию:

### Часть 1. Разработка сервиса
- **Управление клиентами:** CRUD-операции для получателей рассылок (ФИО, Email, комментарий).
- **Управление контентом:** Создание и редактирование шаблонов писем (тема, тело).
- **Управление рассылками:** Настройка временных окон (`start_time`, `end_time`), динамический расчет статуса («Создана», «Запущена», «Завершена»).
- **Логика отправки:** Ручная инициация рассылки с проверкой временных рамок. Для каждого получателя создается запись о попытке отправки с фиксацией статуса и ответа сервера.
- **Валидация:** Защита от создания рассылок с некорректными датами (в прошлом или `start_time` > `end_time`).

### Часть 2. Расширение функционала
- **Аутентификация:** Регистрация с подтверждением email, вход, выход, восстановление пароля.
- **Ролевая модель:** Разграничение прав доступа (пользователь видит только свои данные, менеджер имеет расширенные права просмотра).
- **Статистика:** Отображение ключевых метрик на главной странице (общее количество рассылок, активные рассылки, количество уникальных клиентов).
- **Производительность:** Кэширование страниц для ускорения отображения статистики.

## Структура проекта

- `config/` — настройки проекта (включая конфигурацию кэша и Celery).
- `mailing/` — логика рассылок, модели (Clients, Mailings, Attempts), формы и представления.
- `users/` — система аутентификации и управления пользователями.
- `templates/` — HTML-шаблоны интерфейса.
- `celery_app.py` — конфигурация Celery для асинхронных задач.
